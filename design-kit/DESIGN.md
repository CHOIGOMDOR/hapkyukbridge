# 치즈볼 공부 노트 디자인 시스템

내용(기능·텍스트)은 사이트마다 다르고, **디자인(색·배경·그림·움직임·레이아웃)은 이 문서대로 똑같이** 적용합니다.
정확한 값은 `theme.css`(전체 CSS), `theme.js`(디자인 JS), `reference.html`(실제 완성 페이지)에 있습니다. 애매하면 `reference.html`과 똑같이 만드세요.

## 1. 한눈에 보는 원칙
- **배경은 흰색**(`#fff`). 투명 배경 금지. 글씨는 **검은색 `#111`** 이 기본이고 보조 글씨도 진하게(`#333`~`#444`).
- **글씨체**: `Memoment 꾸꾸꾸`(`assets/fonts/MemomentKkukkukk.woff2`, 용량이 작은 `...subset.woff2`도 있음). 굵기는 400 하나만 쓰고(`font-synthesis:none`) 제목도 굵게 하지 않습니다. 대체 글씨체: Apple SD Gothic Neo → Malgun Gothic → sans-serif.
- **크고 읽기 쉽게**: 큰 제목(히어로 제목 54px, 카드 제목 30px), 본문 17~20px, 아이가 읽는 화면이라 작은 글씨를 피합니다.
- **귀엽고 파스텔**: 둥근 모서리(카드 22px, 칩·버튼 10~16px), 두꺼운 테두리(2.5px), 점무늬·사선무늬·그라데이션, 살짝 떠 있는 그림자(`0 3px 0 var(--tint)`).
- **한국어 줄바꿈**: `word-break:keep-all; overflow-wrap:break-word;` 로 단어 중간이 끊기지 않게 하고, 쪽수·분량 같은 짧은 정보는 **알약(칩)**으로 따로 둡니다. 글자가 세로로 한 글자씩 내려가면 안 됩니다.
- **폰 우선**: 폭 390px에서 먼저 확인합니다. 820px 이하에서는 1열, 탭은 한 줄(`flex:1`, 글자 15~16px, `white-space:nowrap`).

## 2. 요일별 색 (월~일 고정, 매일 바뀜)
`wIdx(날짜)` = 월0 … 일6 (한국 시간 KST 기준). 그날의 색을 CSS 변수 5개로 `:root`에 넣습니다.

| 요일 | 이름 | --pri | --pri2 | --soft | --tint | --deep |
|---|---|---|---|---|---|---|
| 월 | 연보라 | #b9a6f5 | #8fb4f7 | #f4f0ff | #e4dcff | #4b2fb5 |
| 화 | 연하늘 | #8fd0f4 | #7fe3dc | #ebf8fe | #d0eefb | #17618f |
| 수 | 연노랑 | #f5d86e | #ffb877 | #fffae3 | #ffefb0 | #7a5a00 |
| 목 | 연분홍 | #f4a9c8 | #ffb9a0 | #fff1f7 | #ffdbe9 | #a02a62 |
| 금 | 연민트 | #8fdcbf | #b5e88a | #e9faf3 | #cdf2e2 | #17704f |
| 토 | 연살구 | #f7bd98 | #f7a1b4 | #fff3ea | #ffe0cc | #9a4b14 |
| 일 | 연연두 | #c3e38a | #8fe0b0 | #f5fbe6 | #e3f3bf | #3f6a0a |

- `--pri` 메인색(테두리·강조), `--pri2` 그라데이션 짝, `--soft` 가장 연한 배경, `--tint` 중간 배경, `--deep` 진한 강조(체크박스 테두리·말풍선 테두리·그림자).
- 모든 배경·테두리·칩·카드 띠·체크 표시는 이 5개 변수만 씁니다(색을 직접 쓰지 않음). 그래서 하루가 지나면 사이트 전체 분위기가 바뀝니다.
- **날짜에 따른 한 주의 시작은 사이트마다 다릅니다.** 색 매핑은 요일 이름 기준이라 주 시작과 무관합니다.
- 코드: `theme.js`의 `THEMES`, `applyTheme()`. `?date=YYYY-MM-DD` 로 날짜를 바꿔 색을 시험할 수 있게 해 두면 편합니다.

## 3. 배경과 패턴
- 페이지 배경은 흰색. 꾸밈은 **카드·히어로·목표 카드 안**에만 합니다.
- **히어로(첫 큰 카드)**: 여러 겹 배경 — 오른쪽 위 하얀 원, 점무늬(`radial-gradient(var(--pri) 2px…) 30px`), 사선 줄무늬(`repeating-linear-gradient(135deg, 흰색 55% 14px…)`), 바탕 그라데이션(`--tint → --soft → #fff`), 테두리 `0 0 0 3px var(--pri)`. 제목 `h2 em`은 형광펜(아래쪽 절반 `--pri → --pri2` 그라데이션 밑줄).
- **카드**: 위쪽 9px 그라데이션 띠(`--pri → --pri2`) + 연한 점무늬(`--tint`) + 흰 바탕 + 2.5px `--pri` 테두리. 카드 위에 **마스킹 테이프**(`::before`, 74×20px, `--pri` 60%, 살짝 기울임, 짝수 카드는 오른쪽).
- **머리글(header) 아래**: 물결 모양 가장자리(`header::after`, 원 반복 radial-gradient).
- **목표 카드(맨 아래)**: 점무늬 + 사선 줄무늬 + 큰 D-day 박스(둥근 테두리, 살짝 커졌다 작아지는 애니메이션).

## 4. 그림(캐릭터)과 움직임
- 그림은 `<img class="slot" data-kind="..." data-slot="n">` 로 페이지 곳곳(히어로, 카드 제목 옆, 응원 영역, 목표 카드)에 둡니다.
- **그림은 항상 바뀝니다** (아이가 예민해서 같은 그림이 반복되면 안 됨):
  - 페이지를 열 때마다, 탭을 바꿀 때마다, 그림을 눌렀을 때마다 새로 뽑습니다.
  - 같은 화면 안에서는 서로 겹치지 않게, 최근에 보여 준 그림(최대 12장)은 피해서 무작위로 고릅니다(`localStorage` `img-recent`). 코드: `pickImg`, `assignImages`, `setImg`.
  - 그림 목록은 Google Drive 폴더(링크 공유 보기)의 이미지 전체 + 기본 그림. 폴더가 비어도 기본 그림으로 동작. 이미지가 로딩 실패하면 기본 그림으로 대체.
  - 그림은 **많을수록 좋음**(20장 이상 권장). 폴더에 넣기만 하면 자동 반영.
- **움직임**은 그림 파일 이름이나 종류에 따라 정합니다(`kindOf`): `jump`(통통 튐), `crawl`(좌우로 기어감), `sway`(흔들흔들), `float`(둥실, 기본). 키프레임은 `theme.css`의 `jump/crawl/swayy/float/wig/pop/twinkle`. 로고는 `wig`, D-day 박스·말풍선은 `pop`.
- 말풍선(`.bubble`)에는 응원 문구가 무작위로 나옵니다. `prefers-reduced-motion` 이면 애니메이션을 끕니다.
- 그림 파일: `assets/img/*.png` (배경 투명 PNG). 새 사이트도 같은 그림 폴더를 쓰거나 자기 그림 폴더를 만들어 같은 방식으로 연결합니다.

## 5. 공통 부품 (클래스 이름은 theme.css 그대로)
- **머리글**: 둥근 로고 그림(`.logoimg`, 계속 살짝 흔들림) + 사이트 제목(큰 글씨) + **탭 버튼 `nav button`** + 오른쪽에 한국 시간 시계(초 단위, `.clock`).
- **탭 버튼**: 탭마다 고정된 색 + 배경 도형. 현재 탭은 진한 테두리·아래 그림자·살짝 위로. 탭 눌렀을 때 **지연 없이** 바뀌게 `pointerdown` 에 반응(`touch-action:manipulation`). 탭 색 예: 연두 `#e3f6c8/#9bd35a`, 하늘 `#dcecff/#7fb2f5`, 분홍 `#ffe1ec/#f58db0`, 노랑 `#fff1c4/#f5c542` (배경색/도형·테두리색), 각 탭에 원·마름모·모서리 도형(`::before`, `::after`).
- **요일 띠(.week)**: 7칸, 오늘은 `--pri → --pri2` 그라데이션 + 아래 그림자.
- **카드(.card)**, **칩(.chip, 작은 알약)**, **할 일 줄(.task)**: 왼쪽 두꺼운 띠(10px), 체크박스(둥근 사각, 체크 시 그라데이션), 완료되면 사선 줄무늬 배경.
- **알약 분량(.rg)**, **번호 원(①②③)**, **다음 공부 카드(.nx-item c0~c3)**: 번호 원 + 과목 라벨 + 굵은 제목 + 분량 알약. 4가지 포인트색 순환(연두 `#9bd35a/#e3f6c8`, 하늘 `#7fb2f5/#dcecff`, 분홍 `#f58db0/#ffe1ec`, 노랑 `#f5c542/#fff1c4`).
- **접히는 안내 카드(.speak)**, **토스트(.toast, 아래쪽 검은 알림)**, **모달(퀴즈)**, **버튼**: 모두 2.5px 테두리 + 둥근 모서리 + 그라데이션(`--pri → --pri2`).
- **사진 올리기 버튼, 입력칸**: 테두리 2.5px `--pri`, 둥근 14px, 입력 글씨 17px 이상.

## 6. 새 사이트를 만들 때 규칙
1. `theme.css` 전체를 그대로 가져와서 쓰고, 필요 없는 페이지 전용 클래스(퀴즈·모르는 문제 등)는 지워도 됩니다. **색·글씨체·크기·모서리·패턴은 바꾸지 않습니다.**
2. `theme.js`의 `THEMES/applyTheme`, 그림 뽑기, 탭 전환, 시계 코드를 그대로 씁니다.
3. 새 화면도 같은 부품(카드·칩·알약·번호 원·할 일 줄)으로 구성합니다. 새 색이 필요하면 5개 변수를 파생해서 씁니다.
4. 사이트 제목·탭 이름·내용은 자유. 헤더, 요일 색, 그림 교체, 움직임은 동일해야 합니다.
5. 완성하면 폭 390px 폰 화면으로 확인하고(글자 끊김, 가로 스크롤 없음), 요일을 바꿔 7일 모두 색이 바뀌는지 확인합니다.

## 7. 배포 시 주의 (Google Apps Script에 올릴 경우)
- 글씨체와 그림은 파일 경로가 안 먹으므로 **data URI(base64)로 HTML 안에 넣습니다**. 글씨체는 `...subset.woff2`(560KB)를 쓰면 가볍습니다. 방법은 `tools/build_apps_script.py` 참고(같은 저장소).
- Apps Script 웹앱은 iframe 안이라 마이크·일부 팝업(`confirm`)이 막힙니다. 삭제 확인은 버튼을 두 번 누르게 하는 방식을 씁니다.
