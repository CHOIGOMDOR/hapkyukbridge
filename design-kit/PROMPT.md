# 새 채팅에 붙여 넣을 요청문 (design-kit.zip 과 함께 첨부)

아래 내용을 복사해서 새 채팅에 붙여 넣고, `design-kit.zip`(또는 폴더 안 파일들)을 같이 올리세요.

---

첨부한 `design-kit`의 디자인을 **그대로** 적용한 새 웹페이지를 만들어 줘.

[내용(기능)은 이렇게]
- 사이트 이름: (여기에 적기)
- 탭/화면 구성: (여기에 적기)
- 꼭 있어야 하는 기능: (여기에 적기)
- 데이터 저장은: (Google 시트 + Apps Script 웹앱 / 정적 페이지 등 여기에 적기)

[디자인은 반드시 똑같이]
- `DESIGN.md`를 먼저 읽고, `theme.css`, `theme.js`, `reference.html`을 기준으로 해. 색·글씨체·크기·카드·탭·칩·패턴은 바꾸지 마.
- 요일마다 고정된 파스텔 색이 바뀌는 것(월~일 7가지, 한국 시간 기준)을 그대로 적용해.
- 캐릭터 그림이 페이지를 열 때마다, 탭을 바꿀 때마다, 눌렀을 때마다 바뀌고(겹치지 않게, 최근 그림은 피해서), 그림마다 움직임(통통 튐·흔들림·둥실·기어감)이 있는 것도 그대로 해.
- 흰 배경, 검은색 큰 글씨, 한국어 줄바꿈(단어 단위), 폰 화면(390px) 우선.
- 완성 후 폰 크기 화면으로 확인하고, 요일을 바꿔서 색이 바뀌는지 알려 줘.
