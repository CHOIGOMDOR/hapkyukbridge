# 다이어트 벌금장

5명 다이어트 모임용 웹페이지. 각자 매일 체중·단식·운동을 기록하면 벌금이 자동 계산되고,
단톡방에 붙일 한 줄이 만들어집니다. 모든 데이터는 구글 시트 한 장에 모입니다.

## 파일

- `index.html` — 웹페이지 (정적 파일 하나. GitHub Pages 등 어디에 올려도 됨)
- `apps-script.gs` — 구글 시트에 붙이는 Apps Script (시트 읽기/쓰기 + 요약 탭 자동 계산)

## 연결 순서 (5분)

1. 구글 시트 **다이어트 벌금장** 열기 → 메뉴 **확장 프로그램 → Apps Script**
2. 기본 코드를 지우고 `apps-script.gs` 내용을 전부 붙여넣기 → 저장(💾)
3. 오른쪽 위 **배포 → 새 배포** → 유형 선택(⚙) **웹 앱**
   - 실행 주체: **나**
   - 액세스 권한: **모든 사용자**
   - **배포** → 권한 허용(고급 → 안전하지 않은 페이지로 이동 → 허용)
4. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`) 복사
5. 둘 중 하나:
   - `index.html` 의 `var API_URL='';` 에 URL을 넣어 배포하면 멤버들이 바로 사용
   - 또는 페이지를 열고 상단 "구글 시트 연결" 칸에 URL 붙여넣기 (기기마다 한 번)

처음 접속하면 시트에 **기록 / 멤버 / 규칙 / 요약** 탭이 자동으로 만들어집니다.

## 시트 탭

| 탭 | 내용 |
|---|---|
| 기록 | 날짜, 이름, 체중, 단식(O/X), 운동(O/X), 저장시각 |
| 멤버 | 이름, 단식방식, 운동, 시작체중, 목표체중 (페이지 설정에서도 수정 가능) |
| 규칙 | 벌금 금액 4가지 (미기록 / 단식 실패 / 운동 안 함 / 체중 증가) |
| 요약 | 멤버별 최근 체중, 시작 대비, 미기록일, 누적 벌금 — 기록할 때마다 자동 갱신 |

## 벌금 규칙

- 기록을 시작한 다음 날부터, 기록이 없는 날은 **미기록 벌금**
- 단식 실패, 운동 안 함은 각각 벌금
- 직전 기록보다 체중이 올라가면 벌금
- 금액은 **규칙** 탭 또는 페이지 설정에서 변경. 모임 전체에 적용됨.

코드 수정 시 `apps-script.gs` 를 고쳤으면 Apps Script에서 **배포 → 배포 관리 → 새 버전**으로 다시 배포해야 반영됩니다.
