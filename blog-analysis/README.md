## 3. 주제의 흐름 (3단계로 바뀜)

1. **2025-07 ~ 2025-10: 생기부·수시 컨설팅 세일즈 (62건)**

2. **2025-11 ~ 2026-03: 글쓰기·사고력 성장 기록 (약 12건)**
   "성장하는 학생들" 시리즈. 중1·중2 학생의 주차별 글쓰기 결과를 이미지로 올리고 "글쓰기가 사고력과 성적으로 이어진다"는 메시지. 본문 텍스트가 거의 없어 검색 유입에는 불리.

   "영어 공부하는 법", "내신 3~4등급 부모님께", "단기간 성적 향상 비법", "공부는 과학입니다(메타인지 감수성)". 사업 축이 **입시 컨설팅 → 국영수 과외**로 이동한 것이 글에서 그대로 드러납니다. 태그도 중1~고3 학년 태그로 넓어졌습니다.

## 4. 톤 & 문체

- **화자**: "안녕하세요. 합격브릿지(를 운영하는) 지온샘입니다."로 시작하는 1인칭 강사 목소리. 프로필에는 연세대 학·석·박사, 의대·약대·이공계 전문, 전 입시연구소 컨설턴트 경력을 내세움.
- **독자**: 거의 전부 **학부모**("부모님", "내 자녀"). 학생 직접 호명은 드묾.
- **문체**: 경어체 서술형, 단락 짧음, 결론을 먼저 말하고 근거(가르친 학생 사례)를 붙이는 구조. "~해야 합니다", "지금 시작해야 합니다", "반드시", "진짜 비밀" 같은 단정·촉구 표현이 잦음.
- **2025년 글**: 제목이 길고 키워드 나열형(SEO 의식). 본문도 소제목·불릿·이모지(💬 👨‍👩‍👧)·해시태그 뭉치를 넣은 마케팅 포맷. 일부는 노골적 모집 글("수시면접모집 받습니다", "정확히 10명만").
- **2026년 글**: 제목이 짧고 담백해지고("영어 공부하는 법", "공부는 과학입니다."), 해시태그·전화번호가 사라지고, 개인적 성찰과 실제 학생 성적 변화 사례 중심. 신뢰감은 올라갔지만 검색 노출·행동 유도(CTA)는 약해짐.
- **일관된 핵심 주장**: "노력의 양이 아니라 방법", "선이해 후암기", "글쓰기 = 사고력 = 성적", "부모는 정보 수집보다 자녀의 구멍 찾기".
