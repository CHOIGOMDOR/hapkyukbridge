구글 시트 연결

Apps Script 웹앱 URL을 붙여넣으면 5명 기록이 한 시트에 모입니다. 한 번만 하면 이 기기에 저장됩니다.

  1. 시트 → 확장 프로그램 → Apps Script → apps-script.gs 내용 붙여넣기 → 저장
  2. 배포 → 새 배포 → 웹 앱 → 액세스 "모든 사용자" → 배포
  3. 웹앱 URL 복사 → 위에 붙여넣기
